# Crucible

Doomlike hybride en C + SDL2. Mélange Doom (donjon top-down), Vampire Survivor (auto-attaque, bullet hell), Binding of Isaac (combinaisons d'éléments) et Diablo (loot, raretés, fusion).

**Pour installer / lancer / jouer : voir [`Readme.txt`](Readme.txt) — guide pas-à-pas pour Windows.**

## Vue rapide

- 5 héros (Guerrier / Voleur / Mage / Berserker / Paladin)
- 2 armes max + 6 armes possibles (poings / épée / bouclier / arc / bâton / hache) → ~16 sous-classes nommées (Sorcelame, Croisé, Archimage, …)
- 7 éléments (Feu / Eau / Terre / Foudre / Air / Vide / Fée), max 3 greffés par arme, ~30 combos uniques
- Élites avec affinité élémentaire (5% par étage, cap 50%)
- Sensibilités/résistances (Pokémon-like ×2 / ×0.5)
- Inventaire 12 slots + 6 équipements (casque/torse/jambes/bottes/ceinture/gants)
- 5 raretés (Commun → Légendaire +100%) + fusion 3-en-1 (+20%)
- 10 étages avec boss + boutique entre chaque
- Économie double : pièces (run) + éclats d'âme (perm)
- Tout en C, sprites/font/sons procéduraux, aucun asset externe
